Hello ENAM team,

I built **FINN Signal Desk**, a mobile-first prototype for the Push/Pull investment-research workflow. Push combines dated NSE close/volume observations with a small set of issuer results releases, and lets users filter the snapshot and adjust local attention thresholds. Pull gives every watchlist company a cited brief built from its FY2025-26 annual report and latest earnings call, where each figure opens the filing at the cited page. Any other NSE symbol can be researched live, with a cited overview and follow-up questions, using the visitor's own Anthropic API key.

I chose a keyless, static snapshot for the core demo so it is immediately usable and every signal can be checked against its source; live research is optional and needs an API key. The trade-off is that there is no live exchange or filing feed, background alert delivery, or portfolio-wide QoQ/YoY results engine. The Push filing examples are historical FY25 records, and the Push window defaults to all snapshot dates. A next step would connect approved issuer/exchange feeds, add scheduled alerts and fuller quarterly comparisons, and expand source coverage while preserving citation-level traceability.
